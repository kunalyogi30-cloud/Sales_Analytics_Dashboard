# Sales Analytics Dashboard

## Overview
A complete Streamlit Data Analytics internship project for exploring sales, profit, orders, customers, products, channels, categories, and regions.

## Features
- Interactive filters
- KPI cards
- Monthly sales/profit trends
- Category and regional analysis
- Top product analysis
- Automated business insights
- CSV/Excel upload
- Filtered data download

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Files
- `app.py` - Streamlit application
- `requirements.txt` - dependencies
- `data/sales_data.csv` - sample dataset
- `data/data_dictionary.csv` - field definitions
- `PROJECT_REPORT.md` - internship report
